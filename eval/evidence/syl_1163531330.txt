31: #### Аннотация
32: 
33: Предлагаемый курс ориентирован на изучение современных методов и средств организации баз данных, моделей данных (основной акцент — на классической реляционной модели), концептуального моделирования предметной области, даталогического проектирования, использования языка запросов SQL, создания программных приложений, обращающихся к базам данных. В качестве сервера баз данных используется PostgreSQL, в качестве инструментальных языков программирования — Python, Java и Си.Содержание курса соответствует курсу CS270T Databases, входящему в свод знаний по программной инженерии Software Engineering Education Knowledge (SEEK), описанный в документе Software Engineering 2004, определяющий руководящие принципы создания учебных планов для преподавания программной инженерии в высших учебных заведениях. Построение курса отвечает требованиям отечественных профессиональных стандартов в области информационных технологий и международного профессионального стандарта Guide to the Software Engineering Body of Knowledge (SWEBOK) ISO/IEC TR 19759 IEEE.
34: 
35: #### Цель освоения дисциплины
36: 
37: - Овладение студентами классическими и современными подходами к моделированию данных и методами управления данными, позволяющими анализировать, моделировать и проектировать базы данных и разрабатывать программные приложения, использующие базы данных.
38: 
39: #### Планируемые результаты обучения
40: 
41: - Знает основы теории организации и применения баз данных;
42: - Знает место и роль баз данных в информационных системах, основы организации промышленных систем управления базами данных;
43: - Знает современное состояние и тенденции развития систем управления базами данных.
44: - Знает уровни представления данных, основные модели данных, методы организации, поиска и обработки данных;
45: - Знает операции реляционной алгебры;
46: - Знает нормальные формы схем отношений;
47: - Знает типы целостности данных, методы обеспечения целостности данных;
48: - Знает языки запросов, их классификацию и области применения;
49: - Знает язык запросов SQL в части средств описания данных и манипулирования данными;
50: - Знает операторы выборки, добавления, модификации и удаления данных языка запросов SQL;
51: - Знает способы обеспечения независимости и защиты данных с использованием представлений и хранимых процедур;
52: - Умеет выполнять инфологическое проектирование баз данных методом «сущность-связь»;
53: - Умеет выполнять логическое проектирование реляционных баз данных;
54: - Умеет выполнять нормализацию схем отношений реляционных баз данных;
55: - Умеет выбирать типы индексов, создавать и настраивать индексы;
56: - Умеет использовать транзакции;
57: - Умеет получать доступ к данным с помощью курсоров;
58: - Владеет навыками применения методов описания схем баз данных в современных СУБД;
59: - Владеет навыками инфологического проектирования баз данных методом «сущность-связь»;
60: - Владеет навыками нормализации схем отношений реляционных баз данных;
61: - Владеет навыками разработки приложений баз данных, выполняющихся на компьютере пользователя;
62: - Владеет навыками разработки приложений баз данных с веб-интерфейсом;
63: - Владеет в применении средств объектно-реляционного отображения.
64: - Знает принципы работы векторных баз данных и RAG (Retrieval-Augmented Generation) архитектур.
65: - Знает принципы работы векторных баз данных и RAG (Retrieval-Augmented Generation) архитектуры.
66: - Владеет технологиями гибридного поиска (Full-Text Search + Semantic Vector Search).
67: - Умеет использовать векторные базы данных для семантического поиска.
