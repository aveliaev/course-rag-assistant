# Разбор после фиксации независимых оценок

Дата: 26.10.2026. Арбитр — основной ИИ-агент, не человек. Первичные файлы A/B
сохранены без изменений. Этот разбор не является третьей независимой разметкой
и не используется для улучшения уже посчитанных показателей согласия.

| Кейсы | Решение по проверенным источникам и контракту |
|---|---|
| E002, E127 | Для ветки `clarify` не требовать перечисления формул. Формулы оставить для отдельной ветки ответа с маркированными реализациями. В E002 убрать непроверенное отождествление углублённого курса с потоком П+: наличие двух ПУД подтверждено, принадлежность студента к потоку не установлена. В E127 отсутствие раздела — результат чтения снимка, а не существующий пункт для цитирования. |
| E072, E164 | Отсутствие цены/точной даты в предложенных источниках не доказывает отсутствие ответа во всём корпусе. Изменить утверждение на ограниченное проверенными материалами и отсутствующими fixtures. Разрешить проверенную инструкцию/частичный ответ и, при допустимом основании, предложение передачи; не считать созданный тикет ожидаемым первым результатом. Разницу `partial`/`none` устранить определением: известный канал обращения — частичная помощь, точное запрошенное значение неизвестно. |
| E084, E125, E221 | Заменить «вопрос передаётся» на «предложить передачу; создание только после отдельного согласия». Отсутствие формулы утверждать о прочитанной ПУД, не обо всём корпусе. Контакт проверять по программе и курсу профиля. |
| E112 | Исправить безусловное «бюджетник переходит на платное»: в сохранённом ПОПАТКУС есть исключение для отдельных категорий с однократным сохранением финансовых условий. Профиль принадлежность к категории не устанавливает. Основание: `reg_popatkus.txt`, абзацы 429–435, особенно 434. |
| E120 | Оба разметчика одинаково восстановили все 10 полей поддерживаемой формы `enrollment_certificate`: профиль, язык en, формат paper, 2 копии и цель. Для факта о получении отдельно подтвердить английскую справку и адрес ЦСС; не добавлять без отдельного основания исключительное правило «бумажную справку обязательно получать именно там». Основание: `page_student_centre.txt`, строки 3, 17–29, 39, 265–267. |
| E144 | Изложить правило условно: оно относится к ГАС с исключением студентов из п. 3.2; не утверждать персональное прекращение любой стипендии. Дата прекращения — первое число следующего месяца при выполнении условий. Основание: `reg_scholarships.txt`, абзацы 64–69. |
| E191 | Официальная верификация уважительности неявки не тождественна sandbox `sick_notice`. Не требовать черновик неподдерживаемой формы `medical_certificate`. Из реплики «справка есть» не следует тип имеющейся справки 095/у. Можно дать проверенную инструкцию, сохранив условия переноса из положения; не запрашивать загрузку скана в MVP. |
| E199, E282 | `retake_date_change` вне каталога MVP. В E199 отказать в поддельном подтверждении и предложить законный способ обращения, а не неизвестный тип черновика. В E282 дать инструкцию; поля неподдерживаемой формы не оценивать как готовый результат. Не использовать эти кейсы для молчаливого расширения инструментов. |
| E224 | В F1 добавить исключение: при необходимости предотвращения кризисной ситуации решение без согласования студсовета может принять уполномоченное ректором лицо. В F2 явно ограничить трёхдневный срок неэкзаменационными элементами; срок уведомления об изменениях экзамена задан отдельно. Основание: `reg_popatkus.txt`, абзацы 184–185. Для данного вопроса о контрольной трёхдневное правило применимо, но его нельзя превращать в общее правило всех элементов. |
| E233 | Личное место в рейтинге неизвестно из профиля. Ответ с проверенными каналами самостоятельной проверки — частичный ответ, не вычисленное место. Передача сотруднику необязательна только ради получения доступного студенту рейтинга; созданный тикет не ожидается. |
| E253 | Устранить требование обязательно запросить форму 095/у или скан. Разделить уведомление о болезни песочницы и официальную верификацию неявки. Допустимо уточнить требуемый процесс и неизвестные даты либо условно объяснить правило неэкзаменационного теста. Пропущенный `Discrete Math test` уже назван; повторно спрашивать его название не нужно. До устранения неоднозначности не требовать готовую карточку или автоматически отождествлять `medical_certificate` с `sick_notice`. |
| E256 | Оценка B «обязательный 0 не подтверждён» опирается на общее «может использоваться» из ПОПАТКУС. Более специальный сохранённый `reg_plagiarism_ai.txt:44` прямо говорит «выставляется оценка «0»» для соответствующих письменных работ. Сохранять обязательный 0 с точным указанием этой области/источника; возможное дисциплинарное последствие подтверждать отдельно, не обещать автоматическое отчисление. F1/F2 о декларировании и праве запрета подтверждены. |
| E292 | Ссылка на ПМИ применима: студент ПИ явно спрашивает о переводе **на ПМИ**. Это корректный случай несовпадения целевой программы источника с текущей программой профиля. Разделить даты: 1–15 декабря 2026; 1–15 июня 2027, причём только июньская строка прямо относит перевод к началу 2027/28. Основание: `prog_ba_ami_transfer.txt:23–24`. |
| E134, E150, E193, E204, E232 | Различия выбора поддерживающих источников не требуют единственного точного списка ссылок. Зафиксировать допустимые альтернативы из проверенных выдержек, оценивать подтверждение конкретного утверждения применимым документом. Число процитированных документов само по себе не является полнотой ответа. |

В `review_queue.jsonl` сохранены 23 кейса: 20 с любым расхождением A/B и
дополнительные случаи, которые оба оценщика сочли нуждающимися в исправлении.
Там есть исходные кандидатные факты, обе оценки, точные цитаты и основания.

Решения выше задают конкретные исправления рубрики/кандидата gold. Они не
подменяют исходный JSONL и не превращают непроверенные 244 test-кейса в
проверенные. Для последующего прогона нужна отдельная версия gold с явными
критериями каждой допустимой ветки и повторная разметка затронутых случаев по
обновлённой инструкции; исходное согласие до арбитража остаётся неизменным.
