#### Агент-ассистент по материалам курса

**Клиент.** Студент курса. Ценность — быстро получить ответ по пройденному материалу и сразу проверить его по первоисточнику.

**Контракт.** На вопрос пользователя агент ищет информацию в транскриптах лекций, коде курса и истории чата. В ответе каждое существенное утверждение должно быть подтверждено источником: таймкодом лекции, фрагментом кода или сообщением. Если достаточного подтверждения нет, агент отказывается отвечать. Для составных вопросов может последовательно обращаться к нескольким источникам.

**Проблема.** Правдоподобный ответ здесь недостаточен: ошибка особенно опасна, когда ответ выглядит убедительно, но указанная цитата его не подтверждает. Основная сложность — поиск по разнородным данным, чанкинг длинных транскриптов, многошаговый retrieval и оценка качества цитирования.

**Ground truth.** Реальные вопросы студентов + размеченные релевантные фрагменты лекций, кода и чата. Дополнительный набор вопросов, на которые в материалах курса ответа нет, и multi-source вопросов, для которых одного источника недостаточно.

**Baseline.** Hybrid RAG: BM25 + embeddings, reranking и генерация ответа по найденному контексту без агентного многошагового поиска.

**Главный риск темы.** Агент может оказаться ненужным: большинство вопросов могут решаться одним retrieval-запросом. Поэтому агентность должна проверяться экспериментально — на вопросах, где нужно выбрать источник, уточнить поиск или собрать доказательства из нескольких источников.

**Усиленная версия (agentic retrieval).** Агент сам решает, где и в какой последовательности искать: например, сначала находит объяснение концепции в лекции, затем соответствующую реализацию в коде и только после этого формирует ответ. Если найденных доказательств недостаточно, он меняет поисковый запрос или отказывается отвечать. Eval строится на сравнении обычного RAG и агента на реальных вопросах студентов: отдельно single-source, multi-source, multi-hop и вопросы без ответа. Метрики — retrieval recall, correctness, faithfulness, citation correctness/completeness и abstention accuracy. Отдельный eval — подмена цитаты: ответ содержательно верный, но приложенный фрагмент его не подтверждает; проверяем, обнаруживает ли это система.
