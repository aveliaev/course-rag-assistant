#### Агент-помощник студента ФКН НИУ ВШЭ
 
**Клиент.** Студент ФКН: быстро узнать правило со ссылкой на документ и оформить типовую заявку прямо в чате.
 
**Контракт.** Три исхода: ответ со ссылкой на документ ВШЭ для программы студента; черновик заявки (пропуск, справка, больничный), который отправляется только после «Подтвердить»; честное «не знаю» с передачей сотруднику. Действия — в тестовой среде с вымышленными студентами и заглушками систем вуза.
 
**Проблема.** Неверная ссылка, документ не той программы или неверное поле заявки дают реальный вред, а отправка без согласия недопустима.
 
**Ground truth.** Типовые вопросы студентов ФКН с размеченными пунктами документов и эталонные поля заявок, плюс вопросы без ответа и атаки.
 
**Baseline.** Hybrid RAG по документам (BM25 + embeddings, reranking); на просьбу о действии — только ссылка на форму.
 
**Главный риск темы.** Студенту может хватать ссылки на форму, а ошибка в заполненном поле стоит дороже пустой формы — пользу действий проверяем экспериментально.
