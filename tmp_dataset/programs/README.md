`INDEX.md` — читаемый каталог всех программ. `programs.csv` содержит программу, кампус, уровень и ссылки на страницу программы и её документы. `documents.csv` связывает каждый скачанный файл с программами, к которым он относится, и содержит оригинальную ссылку ВШЭ. Подробности по недоступным источникам приведены в `ERRORS.md`.
