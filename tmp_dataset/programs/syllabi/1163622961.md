#### Аннотация

Дисциплина преподается с целью ознакомления слушателей основами разработки на языке Python и основ системного администрирования машин с операционными системами на базе ядра Linux. В рамках магистерской программы «Финансовые технологии и анализ данных» настоящая дисциплина является дисциплиной по выбору. Данный курс является адаптационным. Для освоения учебной должны знать основные классы ИТ-систем, лучшие практики и современные стандарты в сфере информационных технологий. Также студенты должны владеть навыками проектирования информационных систем, уметь систематизировать и обобщать информацию, готовить справочно-аналитические материалы для принятия решений в сфере информационных технологий.

#### Цель освоения дисциплины

- Формирование у обучающихся системы теоретических знаний и практических навыков в области современной разработки программного обеспечения с использованием языка Python в экосистеме операционной системы Linux, обеспечивающих способность решать профессиональные задачи в области проектирования, разработки и отладки высоконагруженных и научно-ориентированных приложений.

#### Планируемые результаты обучения

- Иметь навыки сбора и обработки данных на языке Python
- Обладать базовым уровнем программирования на языке Python
- Уметь писать bash команды в операционной системе Linux
- Иметь базовые навыки для подготовки ладобаторного стенда для демонстрации работы программы
- Уметь подключаться к облачным ресурсам машин по SSH
- Уметь обнаружить неисправность в работе программы и/ил и операционной системы
- Знать базовые конструкции Python и Bash, уметь писать рабочие фрагменты кода «с листа» и понимать, как устроена среда выполнения (Linux)
- Уметь создавать полноценный бэкенд-сервис, готовый к запуску на сервере, документировать код и обосновать свои технические решения
- Связывать теорию с практикой, демонстрировать системное мышление, быть готовым к самостоятельной работе над ИТ-проектами и быстрому поиску решений в нестандартных ситуациях

#### Элементы контроля

- Контрольная работа
Теоретическая: вопросы по архитектуре Linux (команды, файловая система, SSH, переменные) и Python (типы данных, ООП, GIL, декораторы). Практическая: написание небольших фрагментов кода (функции, обработка исключений, работа со строками/списками) и команд Bash для решения конкретной задачи (например, фильтрация логов).
- Проект
Индивидуальный или парный проект, выполняемый в течение семестра. Необходимо разработать сервис на FastAPI/Flask, который: Работает в Linux-окружении (запуск через systemd или Uvicorn). Читает/пишет файлы или подключается к внешнему API (requests). Использует асинхронность (asyncio) или многопроцессорность для тяжелых задач. Содержит логирование, обработку ошибок и базовую документацию (Swagger/README). Финальная сдача — код в Git-репозитории и короткая демонстрация работы (5–7 минут).
- Экзамен
Устный экзамен (собеседование) продолжительностью 15–20 минут. Состоит из двух частей: Теоретический билет: 2–3 вопроса по всему курсу (Linux, Python, ООП, параллелизм, API). Практическая задача: дается проблемная ситуация (например, "упал сервис, как узнать причину?" или "как ускорить медленный скрипт?"), студент предлагает пошаговый план действий и поясняет команды/инструменты.
