#### Аннотация

Дисциплина знакомит студентов с современными подходами и инструментами в области создания цифровых продуктов. В рамках курса студенты изучают жизненный цикл приложений, основы работы в IT-командах, базовые технологии фронтенд-разработки, а также инструменты NoCode/LowCode, позволяющие быстро создавать прототипы и MVP. Особое внимание уделяется практическим заданиям и работе над проектом.

#### Цель освоения дисциплины

- Курс формирует базовое понимание процессов и технологий разработки мобильных и веб-приложений и даёт студентам практические навыки в создании простых прототипов, клиентской и серверной логики с использованием современных инструментов.

#### Планируемые результаты обучения

- Понимать основные этапы жизненного цикла приложений; объяснять роль продуктового подхода в IT.
- Понимать роли в IT-командах; объяснять принципы Agile и Scrum.
- Использовать HTML и CSS для построения простых веб-страниц.
- Применять JavaScript для создания динамических элементов на странице.
- Понимать принципы работы компонентов; собирать простые интерфейсы.
- Создавать прототипы и MVP без программирования.
- Объяснять основы архитектуры клиент–сервер; использовать API для простых задач.
- Разворачивать простые веб-приложения в сети.
- Презентовать проект, демонстрировать навыки командной работы и прототипирования.

#### Содержание учебной дисциплины
