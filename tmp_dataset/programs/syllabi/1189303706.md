#### Аннотация

Курс направлен на изучение практических аспектов разработки и поддержки в промышленных условиях масштабируемых клиент-серверных веб-приложений на языке программирования JavaScript с использованием библиотеки React.

#### Цель освоения дисциплины

- Студенты получат базовые навыки, необходимые для создания современных frontend-приложений с использованием React, TypeScript и дополнительных open-source библиотек.

#### Планируемые результаты обучения

- Использование инструментов типизации TypeScript, Разработка React-компонентов, Взаимодействие с сервером на основе REST API и WebSocket, применение браузерных API, CSS-in-JS стилизация
