#### Аннотация

В результате освоения дисциплины студенты изучат возможности языка программирования Python для обработки и анализа данных. Студенты смогут осуществлять предварительную обработку данных для последующей работы с ними, выбирать подходящий метод анализа в зависимости от типа данных и исследовательской задачи, проводить анализ данных и интерпретировать полученные результаты, представлять их в доступном для широкой аудитории виде.
