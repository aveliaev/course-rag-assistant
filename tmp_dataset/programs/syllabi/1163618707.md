#### Аннотация

Язык программирования Python является одним из самых простых в освоении и популярных языков программирования, а также мощным инструментом анализа данных. С помощью языка Python можно автоматизировать рутинные операции и обрабатывать объемы данных, на несколько порядков превышающие объемы, доступные для обработки вручную или с помощью электронных таблиц. Дисциплина направлена на формирование компетенций в области понимания кода и написания собственных программ на языке программирования Python.

#### Цель освоения дисциплины

- Научиться программировать на языке Python. Научиться эффективно использовать типы данных и библиотеки языка Python.

#### Планируемые результаты обучения

- Понимает структуру кода на Python (отступы, переносы, разделители), основные операторы и концепцию работы переменных; умеет объявлять переменные и использовать их в коде.
- Знает основные типы данных (bool, int, float, str) и умеет писать код с арифметическими и базовыми строковыми операциями; умеет считывать ввод пользователя и выводить результаты.
- Понимает принципы ветвления и циклов; умеет писать код с условным оператором и конструкциями for/while; умеет работать с файлами (чтение/запись, кодировки).
- Знает основные структуры данных (кортежи, списки, множества, словари); умеет реализовывать операции с ними, подбирать структуру под задачу и реализовывать алгоритмы поиска и сортировки.
- Понимает концепции функций и рекурсии, разновидности аргументов; умеет задавать функции, использовать аргументы и применять рекурсию.
- Понимает базовые принципы классов и типизации; умеет задавать классы и применять аннотации типов.
- Умеет устанавливать интерпретатор Python и выполнять код с его помощью.
