#### Аннотация

Курс вводит студентов в практики современной промышленной разработки ПО. Основной формат — работа над индивидуальным или командным проектом в течение семестра/года. Фокус курса — не обзор разных тем из IT, а базовый цикл инженерной разработки: идея → требования → планирование → архитектура → Git → реализация → тесты → документация → демо → ретроспектива. Курс готовит студентов к более продвинутой дисциплине «Промышленная разработка 2», где акцент переносится на code review, CI/CD, production readiness, безопасность и эксплуатацию.

#### Цель освоения дисциплины

- научить выбирать и формулировать инженерную задачу;
- освоить базовую работу с требованиями;
- научить планировать разработку через backlog, roadmap и milestones;
- сформировать начальные навыки архитектурного проектирования;
- научить работать с Git, issues и pull requests;
- дать основы тестирования и документации;
- развить навыки командной работы и технической коммуникации;
- подготовить студентов к защите инженерного проекта;
- помочь сформировать индивидуальный план развития разработчика.

#### Планируемые результаты обучения

- Студент умеет описывать идею проекта, пользователей и ключевые сценарии;
- Студент умеет формулировать MVP, scope и out-of-scope;
- Студент умеет составлять базовые требования и acceptance criteria;
- Студент умеет вести backlog и roadmap;
- Студент умеет оценивать задачи на базовом уровне;
- Студент умеет описывать архитектуру проекта;
- Студент умеет работать с Git, issues, branches и pull requests;
- Студент умеет писать README и инструкцию запуска;
- Студент умеет добавлять базовые тесты;
- Студент умеет проводить простое self-review кода;
- Студент умеет презентовать проект и отвечать на технические вопросы;
- Студент умеет оценивать собственные навыки через матрицу компетенций.
