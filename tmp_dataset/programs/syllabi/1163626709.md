#### Аннотация

Дисциплина направлена на формирование у студентов системного понимания принципов frontend-разработки в контексте проектирования и реализации backend-систем. В рамках курса рассматриваются основы клиентской веб-архитектуры, ключевые концепции языка JavaScript, асинхронная модель выполнения, а также принципы построения современных клиентских приложений на базе компонентного подхода.

#### Цель освоения дисциплины

- Сформировать базовые знания и навыки фронтенд-разработки, которые достаточны для бэкенд-разработки.

#### Планируемые результаты обучения

- Знать: - принципы асинхронного программирования; - основные концепции фреймворка React и библиотек для фронтенд-разработки; - подходы (Controlled/Uncontrolled) и методы стилизации (CSS Modules, styled-components) React-форм; - инструменты для управления состоянием (Context API, useReducer, Redux Toolkit).
- Уметь: - анализировать работу веб-приложения через панель разработчика и применять знания об архитектуре браузера и Event Loop, чтобы находить и устранять узкие места в производительности и ошибки, связанные с безопасностью (CORS, CSP) и рендерингом; - применять продвинутые концепции JavaScript (замыкания, асинхронность, современный синтаксис) и структуры данных при написании кода; - создавать переиспользуемые функциональные компоненты, используя JSX и правильно управляя данными через пропсы.
- Уметь: - управлять внутренним состоянием компонентов с помощью хуков (useState, useEffect, useRef); - настраивать маршрутизацию в SPA с помощью React Router; - интегрировать приложение с внешними API.
- Владеть навыком: - применения инструментов для управления состоянием; - написания unit-тестов для React-приложения; - развертывания React-приложения.

#### Содержание учебной дисциплины

- Создание современных веб-интерфейсов с JavaScript
- DOM и компонентный подход во фронтенде
- Стилизация и адаптивная вёрстка
- Состояние компонентов и работа с формами
- Получение данных с использованием API. Основы взаимодействия фронтенда и бэкенда
- CRUD-операции и обработка ошибок
- Клиентская маршрутизация в React
- Интеграция фронтенда и бэкенда
- Итоговый мини-проект: интерфейс для бэкенд-сервиса
