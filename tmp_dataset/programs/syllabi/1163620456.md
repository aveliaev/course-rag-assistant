#### Аннотация

Студенты освоят современные инструменты разработки, такие как Linux, Git, Bash и Docker. Все эти инструменты нужны чтобы быстро разрабатывать и внедрять ПО в промышленную среду. Практика будет выглядеть как решение задач на Bash, прохождение тестов по лекции, создание собственных Docker образов и внедрению их как контейнеров. Выполнение задач в терминале Linux. На курс стоит идти, чтобы уметь пользоваться современными инструментами для разработки, быстро деплоить собственные приложения, надежно версионировать собственный код, уверенно пользоваться и понимать Linux.

#### Цель освоения дисциплины

- Версионировать код с помощью Git
- Знать синтаксис Bash
- Писать Bash скрипты
- Устанавливать дистрибутивы GNU/Linux
- Создавать докерфайлы для сборки своих образов
- Уметь выполнять базовые команды для работы с GNU/Linux
- Знать основные подходы к версионированию кода
- Управлять контейнерами, понимать ЖЦ контенейра

#### Планируемые результаты обучения

- Создавать bash скрипты для повседневных задач
- Версионировать свой код в разных ветках с помощью Git
- Уметь пользоваться Git
- Создавать свои Docker образы и развертывать их как контейнер
- Понимать синтаксис Bash
- Уметь пользоваться Linux через терминал

#### Элементы контроля

- Домашние задания
- Проектная работа
- Контрольная работа
Проводится после лекции №11 и содержит 7 задач. Задачи 1-3 и 4-6 относятся к тем же типам, что и задачи домашних заданий № 1 и № 2, соответственно, а задача 7 посвящена материалу лекции № 11, т.е. алгоритму Берлекэмпа.
- Экзамен
Экзамен проводится в устной форме. Студент получает билет, который включает в себя два вопроса из программы экзамена – один вопрос по материалу лекций 1-6 и один вопрос по материалу лекций 7-11. Во время подготовки можно использовать любые материалы. После ответа студенту могут быть заданы дополнительные вопросы по программе курса, а также предложены задачи на понимание теоретического материала. Такие задачи не требуют проведения обширных вычислений.
