Курс направлен на приобретение практических навыков решения аналитических задач с использованием Python, формирование умения интерпретировать полученные данные и представление результатов исследования в наглядной форме.

#### Планируемые результаты обучения

- Студенты научатся считывать информацию из файла и записывать в файл с помощью python.
- Студент будет владеть базовым синтаксисом языка python, использовать условные операторы для решения задач
- Студент научатся использовать циклы для решения задач
- Студент научится пользоваться основными структурами данных
- Студенты научатся пользоваться библиотеками, использовать библиотеку numpy для вычислений
- Студент освоит базовый синтаксис библиотеки pandas; применение библиотеки pandas для разведочного анализа данных; использование библиотек matplotlib и seaborn для визуализации данных; использование библиотеки sklearn для построение модели линейной регрессии
- Студент освоят основы объекто-ориентированного программирования
