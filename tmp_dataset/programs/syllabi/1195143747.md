#### Abstract

This course is intended either (A) for student theoretical computer science or (B) student software engineering with both an interest in theory and implementing large brute force searchers. For certain hard NP-hard problems, one is interested in exact solutions at the price of implementing exponential searches. For example, one wants to minize the size of circuits that perform common operations or optimize the use of expensive industrial machines. Even 0.1 percent improvement of an objective might mean a significant gain that justifies large scale computations. This course studies how to optimize exponential searches. A classical example is the vertex cover problem: it could be solved reasonably efficiently on arbitrarily large graph, provided the minimal vertex cover is small. In fact, you might have learned that it can be solved in time 2knO(1) on graphs with n nodes, provided there exists a vertex cover of size at most k. Moreover, this is practical if k ≤ 50, even if n is in the millions. With more advanced techniques, one can improve this to O(k ∗ 1.2738k + kn) and practical variants exist that work for k ≤ 200. This even includes adversarial examples generated with crypto. In the 1st part of the course, we study these algorithmic techniques theoretically. In the last 4 lectures, this course differentiates. – Students with a pure theory profile will learn on how to prove the absence of efficient search for certain problems, called parameterized hardness. – Students with an applied interest will learn to implement these techniques with and without LLM’s.

#### Learning Objectives

- Algorithmic techniques for planar graphs.
- Prove lower bounds on exponential factors using the (strong) exponential time hypothesis.
- Implement problem reduction strategy based on theoretical analysis. Optimize branching algorithms. Implement kernels from linear programming.

#### Expected Learning Outcomes

- Formally define parameterized problems, fixed-parameter tractability (FPT), XP algorithms, kernels. Prove correctness and running-time bounds for nontrivial parameterized algorithms.
- Design and analyze FPT algorithms using branching, kernelization, color coding, iterative compression, dynamic programming, separator methods, algebraic methods, and randomized techniques.
- Algorithms parameterized by treewidth, feedback vertex set number, deletion distance, solution size, or structural graph parameters. Apply Courcelle’s theorem.
- W[1]-hardness or W[2]-hardness for proving that FPT hardness does not exist.
