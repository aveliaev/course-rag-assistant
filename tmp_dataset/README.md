# Корпус документов для RAG-помощника студента ФКН

Корпус содержит только факультет компьютерных наук: 23 программы ФКН (Москва) и общеуниверситетские документы ВШЭ, которые на них распространяются. Снимок сайта — 3 и 24 октября 2026 года (`downloaded_at`).

Единственный источник правды о документах — `registry.csv`: одна строка на документ, у каждого документа один `doc_id`. Golden-датасет ссылается на `doc_id`, а не на путь к файлу. Всего 1829 документов, около 180 МиБ.

| Путь | Что лежит | Индексировать |

| `regulations/cards/reg_*.html` | карточки положений на hse.ru/docs: даты, приказ, без текста | нет, метаданные уже в реестре |
| `pages/*.md` | страницы справочника студента, сервисов и ФКН | да |
| `raw_html/*.html` | исходный HTML тех же страниц | нет, дубль `pages/` |
| `programs/pages/*.md` | страницы и разделы сайтов программ | да |
| `programs/raw_html/*.html` | исходный HTML тех же страниц | нет, дубль `programs/pages/` |
| `programs/syllabi/*.md` | ПУД | да |
| `programs/syllabi/raw_html/*.html` | исходный HTML тех же ПУД | нет, дубль `programs/syllabi/` |
| `programs/files/pf_*` | файлы программ (pdf, docx, doc, xlsx) | да |
| `programs/programs.csv` | 23 программы ФКН: название, уровень, ссылки | — |

Индексируется только колонка `path`. Дубли того же документа перечислены в `alt_paths` и в индекс не попадают, поэтому при подсчёте recall по `doc_id` «не тот дубль» не возникает. Побайтово одинаковые файлы хранятся один раз.

## `doc_id`

- `reg_<тема>` — положение (`reg_popatkus`, `reg_scholarships`), `reg_<тема>_app<N>` — приложение N к нему (`reg_popatkus_app5`);
- `page_<тема>` — страница справочника, сервиса или ФКН (`page_missed_exam`, `page_fcs_stipend_excellent`);
- `prog_<program_id>` — страница документов программы (`prog_ba_ami`), `prog_<program_id>_<раздел>` — раздел её сайта (`prog_ba_ami_uo`, `prog_ma_datasci_references`);
- `syl_<id курса на hse.ru>` — ПУД (`syl_1163609050`);
- `pf_<вид>_<sha8>` — файл программы; вид: `curriculum`, `workplan`, `schedule`, `form`, `practice`, `thesis_guide`, `gia_program`, `project_rules`, `booklet`, `upbringing`, `program_doc`. Вид определяется по названию ссылки автоматически, это эвристика.

Один файл может относиться к нескольким программам: `program_ids` перечисляет их через `;`. Например, одинаковые шаблоны заявлений магистратуры ФКН хранятся одной строкой.

## Колонки, важные для датасета

- `scope`: `university` — действует для всех программ (положения, справочник, приказы о воспитательной работе); `program` — относится к программам из `program_ids`.
- `relevance`: сейчас у всех `target` — ловушки из других факультетов удалены.
- `adopted_date`, `effective_date`, `order` — для положений, взяты с карточек hse.ru/docs.
- `intake_year` — год набора для учебных планов, рабочих планов и графиков; `academic_year` — учебный год рабочего плана или ПУД. Правильный план зависит от года набора студента.
- `notes` у ПУД — статус и когда читается («Курс обязательный; 1-й курс, 2 модуль»). У 50 ПУД на сайте опубликована только шапка курса, это отмечено в `notes`.
- `sha256`, `orig_paths` — проверка целостности и старые пути.

## Схема golden-датасета (предложение)

```
id, question, student_program_id, expected_behavior, gold_doc_ids, gold_quote, request_type, request_fields, notes
```

- `expected_behavior`: `answer` | `draft_request` | `handoff` | `resist_attack`.
- `gold_doc_ids` — один или несколько `doc_id` через `;`; для `handoff` пусто.
- `student_program_id` — из `programs/programs.csv`. Кейсы «документ не той программы» теперь строятся внутри ФКН: например, студент ПИ спрашивает про формулу оценки курса, а в корпусе есть одноимённые ПУД ПМИ и КНАД; или магистрант спрашивает о правилах аттестации, а `reg_popatkus_app9` действует только для «Математики машинного обучения».
- `request_type` и `request_fields` (JSON) — только для `draft_request`. Опора для эталонных полей — бланки (`doc_kind = form`) и разделы `*_application`, `*_references`, `*_uo`.
- Для `handoff` есть контакты учебных офисов и менеджеров программ (`prog_*_uo`, `prog_*_study_office`, `prog_*_studyoffice`).

## Как собирался корпус

1. 3 октября 2026: каталог программ ВШЭ, страницы документов программ, 11 положений и 26 страниц справочника.
2. 24 октября 2026: из корпуса удалены 69 побайтовых копий файлов, а затем все программы не ФКН и их файлы. Добавлены учебные планы и графики программ ФКН, ПУД, разделы сайтов программ с приложенными файлами, страницы стипендий ФКН, положения о стипендиях и практической подготовке, приложения к ПОПАТКУС.

Исключено при сборе:

- каталоги ВКР, рейтинги, доски объявлений, страницы выпускников и достижений, а также два файла со списками студентов (претенденты на скидку, распределение по защитам ВКР) — в них персональные данные студентов;
- новости, разделы для абитуриентов, страницы-формы без текста;
- английские версии учебных планов, если есть русские (у `ba_data` есть только английские);
- Вики ФКН (wiki.cs.hse.ru) — неофициальный сайт вне hse.ru.

Контакты сотрудников учебных офисов, состав ГЭК и научные руководители оставлены: это публичная информация с hse.ru, нужная для передачи вопроса сотруднику.

## Известные ограничения

- `reg_scholarships` — редакция 2022 года, `page_fcs_internship` озаглавлена «… в 2024 году»; перед разметкой стоит проверить актуальность.
- 76 файлов в старом формате `.doc` — при индексации их нужно конвертировать отдельно (`python-docx` их не читает).
- Несколько разделов сайтов (расписания сессий, «О программе» части магистратур) подгружаются скриптами и в корпус не попали.
