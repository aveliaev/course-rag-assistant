# Корпус документов для RAG-помощника студента ФКН

Корпус содержит только факультет компьютерных наук: 23 программы ФКН (Москва) и общеуниверситетские документы ВШЭ, которые на них распространяются. Снимок сайта — 3 и 24 октября 2026 года (`downloaded_at`).

Единственный источник правды о документах — `registry.csv`: одна строка на документ, у каждого документа один `doc_id`. Golden-датасет ссылается на `doc_id`, а не на путь к файлу. Всего 1828 документов, около 180 МиБ. Каждый индексируемый файл читается обычными парсерами: `.md`, `.docx`, `.pdf` с текстовым слоем, `.xlsx`.

Индексируется только колонка `path`. Дубли того же документа перечислены в `alt_paths` и в индекс не попадают, поэтому при подсчёте recall по `doc_id` «не тот дубль» не возникает. Побайтово одинаковые файлы хранятся один раз.

## `doc_id`

- `reg_<тема>` — положение (`reg_popatkus`, `reg_scholarships`), `reg_<тема>_app<N>` — приложение N к нему (`reg_popatkus_app5`);
- `page_<тема>` — страница справочника, сервиса или ФКН (`page_missed_exam`, `page_fcs_stipend_excellent`);
- `prog_<program_id>` — страница документов программы (`prog_ba_ami`), `prog_<program_id>_<раздел>` — раздел её сайта (`prog_ba_ami_uo`, `prog_ma_datasci_references`);
- `syl_<id курса на hse.ru>` — ПУД (`syl_1163609050`);
- `pf_<вид>_<sha8>` — файл программы; вид: `curriculum`, `workplan`, `schedule`, `form`, `practice`, `thesis_guide`, `gia_program`, `project_rules`, `booklet`, `upbringing`, `program_doc`. Вид определяется по названию ссылки автоматически, это эвристика.

Один файл может относиться к нескольким программам: `program_ids` перечисляет их через `;`. Например, одинаковые шаблоны заявлений магистратуры ФКН хранятся одной строкой.

## Колонки, важные для датасета

- `scope`: `university` — действует для всех программ (положения, справочник, приказы о воспитательной работе); `program` — относится к программам из `program_ids`.
- `relevance`: сейчас у всех `target` — ловушки из других факультетов удалены.
- `adopted_date`, `effective_date`, `order` — для положений, взяты с карточек hse.ru/docs.
- `intake_year` — год набора для учебных планов, рабочих планов и графиков; `academic_year` — учебный год рабочего плана или ПУД. Правильный план зависит от года набора студента.
- `is_current` — действует ли документ в 2026/2027 учебном году: `true` / `false` / `unknown`. Определяется правилами: положения — по карточке hse.ru/docs (утратившие силу не скачивались); рабочие планы и ПУД — по `academic_year`; учебные планы и графики — `true` (на сайте только действующие наборы); остальное — по году в названии (прошлые учебные годы и наборы, которые уже выпустились, — `false`); страницы сайта без даты — `true`, файлы без даты — `unknown`. Для кейсов «модель взяла неактуальную редакцию» берите документы с `false` (80 штук: прошлые рабочие планы, приказы о воспитательной работе прошлых лет, `page_fcs_internship` за 2024 год и др.).
- `text_chars` — сколько символов текста извлекается из `path`. Документы с малым значением бесполезны как `gold_doc_ids`.
- `has_grading_rules` (только ПУД) — есть ли в разделе «Промежуточная аттестация» формула или правило оценки: `true` у 628, `false` у 259. Вопросы о формуле по курсам с `false` должны вести к `handoff`, а не к `answer`.
- `notes` у ПУД — статус и когда читается («Курс обязательный; 1-й курс, 2 модуль»), пометки «только шапка» и «нет правила оценки». У файлов — пометки о конвертации из `.doc` и OCR.
- `sha256`, `orig_paths` — проверка целостности и старые пути.

## Шаблон golden-датасета

Сам датасет пока не размечен. [`golden_template.jsonl`](golden_template.jsonl) — шаблон: по одной заготовке на каждый `expected_behavior` (`answer`, `draft_request`, `handoff`, `resist_attack`). В угловых скобках — что подставить, `null` и пустые списки — необязательные поля. Новые кейсы делаются копированием подходящей строки.

Формат — JSONL, одна запись на кейс. Пример заполненной записи:

```json
{
  "id": "fkn_0001",
  "question": "завалил экзамен по матану в декабре, когда пересдача и сколько попыток?",
  "student_program_id": "ba_ami",
  "intake_year": 2025,
  "expected_behavior": "answer",
  "gold_doc_ids": ["page_knowledge_control"],
  "acceptable_doc_ids": ["reg_popatkus", "page_repeated_courses"],
  "gold_quote": "Первая пересдача проводится преподавателем",
  "key_facts": ["10 января — 15 февраля", "две пересдачи", "вторая — комиссия не менее 3 человек", "после второй — отчисление"],
  "forbidden_facts": ["1 сентября — 15 октября", "три пересдачи"],
  "request_type": null,
  "request_fields": null,
  "notes": "период для 1–2 модуля; в той же таблице есть период 3–4 модуля — проверка на выбор строки"
}
```

- `expected_behavior`: `answer` | `draft_request` | `handoff` | `resist_attack`.
- `gold_doc_ids` — документы, где ответ сформулирован; `acceptable_doc_ids` — где то же правило тоже есть (положение и справочник часто дублируют друг друга), их попадание не считается промахом. Для `handoff` оба пусты.
- `key_facts` / `forbidden_facts` — что ответ обязан и не должен содержать; одного `gold_quote` мало для автоматической оценки.
- `distractor_doc_ids` — документы-ловушки: одноимённая ПУД другой программы, учебный план другого набора, устаревший бланк. Если ретривер или ответ опирается на них — это ошибка кейса.
- `case_tags` — для срезов метрик: `wrong_program`, `wrong_intake`, `stale_document`, `program_specific_rule`, `prompt_injection`, `pii` и др.
- В `request_fields` значение `null` означает, что студент это поле не назвал, и агент должен спросить, а не придумать.
- `student_program_id` — из `programs/programs.csv`; `intake_year` — год набора студента: от него зависит, какой учебный план правильный (в корпусе наборы 2023–2026). Кейсы «документ не той программы» теперь строятся внутри ФКН: например, студент ПИ спрашивает про формулу оценки курса, а в корпусе есть одноимённые ПУД ПМИ и КНАД; или магистрант спрашивает о правилах аттестации, а `reg_popatkus_app9` действует только для «Математики машинного обучения».
- `request_type` и `request_fields` (JSON) — только для `draft_request`. Опора для эталонных полей — бланки (`doc_kind = form`) и разделы `*_application`, `*_references`, `*_uo`.
- Для `handoff` есть контакты учебных офисов и менеджеров программ (`prog_*_uo`, `prog_*_study_office`, `prog_*_studyoffice`).
- 94 названия ПУД встречаются больше чем в одной программе — готовый материал для кейсов «не та программа»; для них `student_program_id` обязателен.
- Документов по программам очень по-разному (ПМИ — около 300, `ma_sdhd` — 19): для маленьких программ большинство честных кейсов будут `handoff`, их стоит заложить отдельно.

## Как собирался корпус

1. 3 октября 2026: каталог программ ВШЭ, страницы документов программ, 11 положений и 26 страниц справочника.
2. 24 октября 2026: из корпуса удалены 69 побайтовых копий файлов, а затем все программы не ФКН и их файлы. Добавлены учебные планы и графики программ ФКН, ПУД, разделы сайтов программ с приложенными файлами, страницы стипендий ФКН, положения о стипендиях и практической подготовке, приложения к ПОПАТКУС.

Исключено при сборе:

- каталоги ВКР, рейтинги, доски объявлений, страницы выпускников и достижений, а также два файла со списками студентов (претенденты на скидку, распределение по защитам ВКР) — в них персональные данные студентов;
- новости, разделы для абитуриентов, страницы-формы без текста;
- английские версии учебных планов, если есть русские (у `ba_data` есть только английские);
- Вики ФКН (wiki.cs.hse.ru) — неофициальный сайт вне hse.ru.

Контакты сотрудников учебных офисов, состав ГЭК и научные руководители оставлены: это публичная информация с hse.ru, нужная для передачи вопроса сотруднику.

## Постобработка

- 76 файлов `.doc` (из них 62 бланка) сконвертированы в `.docx` встроенным в macOS `textutil`; оригиналы остались в `alt_paths`.
- 12 PDF без текстового слоя (5 приказов о воспитательной работе, лист ознакомления с ЛНА, соглашение об электронном взаимодействии, требования к фотографиям и др.) распознаны встроенным в macOS OCR (Vision, русский и английский) в `*.ocr.md`; исходные PDF — в `alt_paths`. В распознанном тексте возможны ошибки, цитаты для `gold_quote` из них стоит сверять с PDF.
- `page_fcs_cppr` удалена: на странице была только одна новость.
- У `reg_transfer` исправлена ссылка: в исходном `sources.csv` она не была взята в кавычки и разъехалась по трём колонкам; запятые в ней теперь закодированы как `%2C`.

## Известные ограничения

- `reg_scholarships` — редакция 2022 года (по карточке действующая, `is_current = true`), но стоит проверить, нет ли более новой редакции.
- Несколько разделов сайтов (расписания сессий, «О программе» части магистратур) подгружаются скриптами и в корпус не попали.
- Вики ФКН (wiki.cs.hse.ru) на 24.10.2026 не отвечает на подключения ни из терминала, ни из браузера; есть копия в Web Archive от 20.10.2026 с разделом «Курсы за 2026/27 учебный год».
