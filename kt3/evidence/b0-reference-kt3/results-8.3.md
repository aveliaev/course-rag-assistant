## Воспроизведение

Коллекция индекса — kt3_b0_002900212313f9f1, порог RRF — **0,50**. При проверке локальная версия отвергла старый отпечаток калибровки. Калибровка на фиксированной smoke-выборке дала одинаковый результат для порогов 0,45, 0,50 и 0,55. Выбран 0,50 по правилу разрешения ничьей в харнессе. Старый замер RAG с формами использовал порог 0,55.

База исходников — c61fdd5. Локальные изменения раннера сохранены в source.patch, хеши кода и точный промпт — в run.json. Для воспроизведения с зафиксированным индексом скопируйте calibration.json из пакета замера в kt3/.cache/retrieval.json и запустите из корня репозитория.

~~~sh
PYTHONPATH=kt3/src kt3/.venv/bin/python -m fkn_assistant.evaluation.runner \
  --variant rag-b0-reference --dataset dev --repeats 3 \
  --output kt3/runs/b0-reference-kt3
~~~
