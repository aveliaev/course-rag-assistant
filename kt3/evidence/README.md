# Артефакты замера КТ3

В каталоге лежат зафиксированная калибровка B0, семь диалогов, конфигурация, сводка и пакет для ручной оценки. Архив содержит записи всех ходов dev и smoke, сырые ответы модели, выдержки, результаты проверок и время.

Из корня проекта можно восстановить папки прогонов и пересчитать отчёт:

~~~sh
mkdir -p kt3/runs/from-archive
tar -xzf kt3/evidence/b0-run.tar.gz -C kt3/runs/from-archive
kt3/.venv/bin/fkn-report kt3/runs/from-archive/dev
kt3/.venv/bin/fkn-report kt3/runs/from-archive/dev --review
~~~

В составе архива есть сценарии, оба smoke-прогона и точная копия скрипта запуска, использованного для замера. Документы и данные для воспроизведения определены хешами в dev/run.json. В пакет ручной оценки входят вопросы из dev, синтетические профили и выдержки из корпуса.

## Проверка в отдельном клоне

Окружение установлено заново из lock-файла. Корпус из 1 828 документов дал те же 19 670 фрагментов, включая локаторы. Из них 13 704 вектора вычислены заново и побайтно совпали с сохранённым индексом. Для оставшихся 5 966 фрагментов использован проверенный локальный кэш. Индекс загружен в отдельный Qdrant. На отдельных контейнерах прошли 7 тестов, 7 диалогов и живой smoke из 20 ходов. Отчёт и ручная выборка воспроизвелись из архива побайтно. [Сводка smoke](clean-smoke-summary.json)

Архив и исходные метаданные фиксируют структуру на момент замера. После переноса файлов рабочая калибровка хранится в infra/retrieval-calibration.json. Порог, индекс и входные данные сохранены.

## Предварительная проверка ответов B0

[`b0-grades-codex.jsonl`](b0-grades-codex.jsonl) содержит оценку Codex ровно 50 ответов первого повтора из архива, с четырьмя критериями и объяснениями по ID. Критерий `evidence` применяется к существенным утверждениям и правилам форм. `safety` фиксирует запреты на действия, разглашение и отдельные запретные факты. Общая неподтверждённость текста учитывается в `evidence`. Поля форм сверены в рамках локального выпуска `kt3-local-sandbox-v2`.

Для отчёта после извлечения архива:

~~~sh
kt3/.venv/bin/fkn-report kt3/runs/from-archive/dev --grades kt3/evidence/b0-grades-codex.jsonl
~~~

Человеческая сверка выполняется отдельно. Два участника сохраняют первичные оценки 10 отмеченных кейсов, затем считают согласие и фиксируют результаты. В итоговые метки входят решения по всем 50 ответам после разбора расхождений.

## Сопоставимый контрольный прогон

[`search-only-run.tar.gz`](search-only-run.tar.gz) содержит ответы, метаданные и сводку всех 148 ходов без генерации. [Парный отчёт](../docs/results-search-only.md) сравнивает первый повтор с B0. [B1 smoke](b1-fixture-smoke.json) содержит результат проверки исполнения на фикстуре модели.

~~~sh
tar -xzf kt3/evidence/search-only-run.tar.gz -C kt3/runs/from-archive
kt3/.venv/bin/fkn-report kt3/runs/from-archive/dev --compare kt3/runs/from-archive/search-only
~~~
